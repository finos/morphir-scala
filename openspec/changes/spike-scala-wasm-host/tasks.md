# Tasks

Implementation is in progress. These tasks implement the experiments in [design.html](design.html), not a production host. Initial planning is tracked in `morphir-a9k`; execution, including the approved Extism FFM candidate and footprint profiling, is tracked in `morphir-1k0`. The first six-configuration checkpoint was retained after 45 minutes in `.dev/.sdlc/scala-wasm-host/out/first-checkpoint.json`. Keep final receipts and charts in that ignored evidence directory. The early FFM proof used the direct fallback after the RC7 generator rejected typed callback pointers. All three candidates remain in scope on JVM and Native Image; negative qualification results remain evidence.

Complete an experiment task when it has run and its evidence is recorded, even if the result rejects a candidate. Never mark an unrun dependent experiment complete. Record blocked configurations and continue independent ones; request a scope revision if blocked tasks must be removed before archive.

The footprint collection is retained as 144 runs: 120 completed and 24 refused GraalWasm Python runs. Endive and FFM pass eight SDK/Python legacy MCK guest runs plus independent report checks. The FFM absolute memory ceiling fails on both targets. Report sources are Scala/Mill; generated charts and raw receipts stay under `.dev/.sdlc/scala-wasm-host/out/report/`. Runtime heap capacity is defined by its API rather than called OS committed memory, and fresh-process trials do not flush caches. Fully instrumentation-free timings and exact native allocation attribution remain unavailable. Task 4.3 stays blocked and unrun until the pinned MoonBit compiler/core dependency mismatch is resolved; do not archive this change while that work remains.
