MoonBit compiler runs on JVM and Native Image

GraalJS + GraalWasm 25.5.5.0.3 loads the pinned Wasm compiler, compiles a tiny MoonBit function and executes its emitted 173-byte Wasm with answer 42. A second source returns 43 through the unchanged host executable. No native moonc or Node process is used.

The unmodified loader fails when a repeated import name has decreasing arity. A tested in-memory import-name adapter fixes the regression. Receipts verify every non-import section remains unchanged and retain original/adapted SHA-256 hashes. This is a compatibility workaround, not unmodified upstream support.
